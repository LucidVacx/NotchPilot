# Changelog

## 0.3.1 — 2026-09-11

First public binary release of the native terminal edition.

- Real Hermes CLI embedded in a native terminal.
- Smooth reveal with support for other apps' fullscreen Spaces.
- Solid black crown with a graduated translucent background.
- Small notch on external displays.
- Direct mouse-wheel open/close with immediate direction changes.
- Persistent terminal session while the panel is hidden.

Requires macOS 15+, Apple silicon and an existing Hermes CLI installation.
